# WarpEdit

Spec pack for the Warp plugin harness. Scan this folder with `/warp-scan`.

- `spec/CURSOR_PLAN.md` and `plan/schedule.json` — the graph
- `tickets/jira-import.json` — Jira JSON import
- `tickets/linear-import.json` — Linear API import with blockers
- `ui/build-map.html` — example screen

Day 0 assumes WarpView is already built. WE-01 is the gate that records that.
